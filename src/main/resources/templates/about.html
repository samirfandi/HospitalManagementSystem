About the Project

Hospital Management System (HMS)

A full-stack web application designed to simplify hospital patient management through a secure, organized, and user-friendly interface.

Built with the Spring ecosystem, this project demonstrates the integration of backend development, database management, authentication, authorization, and server-side rendering.

Spring MVC Spring Data JPA Spring Security Thymeleaf Bootstrap

Project Overview

A complete patient management solution

Architecture Full Stack MVC
Backend Spring Boot
Database H2 / MySQL
Security Role-Based Access

What Does This Project Offer?

Essential features for managing patient information efficiently and securely.

Patient Management

View, manage, and update patient information through an organized management interface.

Authentication & Security

Secure access using Spring Security with authentication and role-based authorization.

Role-Based Access

Different permissions for administrators and regular users to ensure controlled access to features.

Technologies & Tools

Built using modern Java technologies and frameworks.

Backend Development
  • Spring MVC - Handles web requests and application flow.
  • Spring Data JPA - Simplifies database operations and persistence.
  • Spring Security - Manages authentication and authorization.
  • Thymeleaf - Renders dynamic HTML pages.
Frontend Development
  • HTML5 - Structures the web pages.
  • CSS3 - Provides styling and visual customization.
  • Bootstrap - Creates responsive layouts and components.
  • Thymeleaf - Integrates backend data into HTML templates.

Database Configuration

The application supports two database configurations.

Default Configuration
H2 Database

The project uses H2 as its default database configuration.

  • Easy setup and configuration
  • Suitable for development and testing
  • H2 Console for database inspection
Alternative Configuration
MySQL Database

MySQL can be used as an alternative database by configuring the application datasource.

  • Install and start MySQL Server
  • Configure the datasource URL
  • Set the database username and password
  • Disable the H2 configuration

Security & Authentication

Two authentication strategies are available through the Spring Security configuration.

In-Memory Authentication
Default Strategy

User details are stored directly in memory using Spring Security's in-memory authentication mechanism.

This configuration is convenient for development and demonstration purposes.

Database-Based Authentication
Alternative Strategy

User details are retrieved from the application's database through a custom UserDetailsService implementation.

This approach allows user information to be managed and persisted in the database.

User Roles & Permissions

Access to patient management features depends on the user's assigned role.

USER
Regular User

Regular users can access patient information and update existing patient records.

  • View patient list
  • Modify patient information
ADMIN
Administrator

Administrators have access to all patient management operations.

  • View patient list
  • Modify patient information
  • Add new patients
  • Delete patients
